# ✨ Aleena Saji | Personal Portfolio

Welcome to the source code for my personal portfolio website! This project serves as a digital resume and a showcase of my featured work, technical skills, and educational background.

## 🎨 Design Aesthetic
The site is built with a custom **Dreamy Twilight & Pastel** theme, featuring:
- 🌄 A dynamic background gradient that transitions from twilight blue to evening sky as you scroll.
- 🪟 Elegant **Glassmorphism** UI components (frosted glass cards).
- 🌸 Carefully curated pastel accents (pink, gold, and sage green).
- 🖋️ Beautiful typography using **Lora** (serif) and **Outfit** (sans-serif).
- ✨ Smooth CSS animations, floating blobs, and scroll-triggered fade-ins.

## 🛠️ Tech Stack
This project is built from scratch entirely with vanilla web technologies. No heavy frameworks!
* **HTML5** (Semantic structure)
* **CSS3** (Custom properties, Flexbox/Grid, Keyframe animations)
* **Vanilla JavaScript** (Intersection Observers for scroll animations, DOM manipulation for mobile navigation)
* **FontAwesome** (Icons)

## 🚀 How to Run Locally

Since this is a vanilla static site, running it locally is incredibly easy. You don't need to install any packages!

**Option 1: The Simplest Way**
Simply open the folder and double-click the `index.html` file to view it in your default web browser.

**Option 2: Using a Local Server (Python)**
If you want to view it via a local development server, open your terminal in the project directory and run:
```bash
python -m http.server 8000
```
Then navigate to `http://localhost:8000` in your browser.

**Option 3: VS Code Live Server**
If you use VS Code, install the "Live Server" extension, right-click `index.html`, and select "Open with Live Server".
